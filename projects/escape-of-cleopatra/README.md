# Escape of Cleopatra

Escape of Cleopatra is a Unity game developed as part of a Game Development course project.

The project was created collaboratively and later published on itch.io.

## About the Project

Players must navigate through an Egyptian-themed environment while overcoming challenges and progressing toward escape.

The project provided practical experience in:

- Unity development
- C# programming
- Team collaboration
- Project planning
- Game design implementation
- UI prototyping

## Publication

The game is publicly available on itch.io:

https://3linameier.itch.io/escape-of-cleopatra
